# Vangnet

Zakhulpje voor ADHD en ADD. Je gooit erin wat je wilt onthouden; de app brengt het terug
en onthoudt welk zetje bij jou werkt. Geen intake, geen streaks, geen account.

**Alles blijft op je eigen toestel.** Er is geen server en er wordt niets verzonden.
Koppel je optioneel je eigen AI-sleutel, dan gaat alleen de tekst van dat ene item
rechtstreeks naar de aanbieder die jij kiest.

Hulpmiddel, geen behandeling.

Bij een vaag moment zoals "binnenkort" kun je een snel voorstel kiezen of zelf iedere toekomstige
datum en tijd plannen. In het weekend wijst "Volgende werkdag" naar maandagochtend.

## Op je telefoon zetten

Open de site in Safari (iPhone) of Chrome (Android), kies Delen en dan
"Zet op beginscherm".

## Zelf draaien

Statische site, geen bouwstap. `index.html` openen volstaat, al werken
service worker en installeren alleen via https.
